Before you start

Four things and you're ready.

✓ A laptop (Mac or Windows) + charger
✓ The OpenAI key we share on the day
✓ Wi-Fi connected
✓ About 30 minutes
01

Install the basics

Two free tools power everything today: Node.js runs the bot, and Git downloads the code.

Node.js — go to nodejs.org and download the LTS installer. Open it and click through, keeping the defaults. Git — grab it from git-scm.com (most Macs already have it).

Then check it worked. Open Terminal (Mac) or PowerShell (Windows) and paste:

node -v
git --version
💡
See two version numbers like v22.11.0? You're good. If not, close the terminal, reopen it, and try again.
02

Get the code

Download the workshop project to your laptop. Paste this in your terminal:

git clone <REPO_URL>
cd hermes-bot
🔗
Replace <REPO_URL> with the link we drop in the workshop chat.
📸 Placeholder — screenshot of the GitHub repo's green “Code” button.
03

Add your OpenAI key

The bot needs a key to talk to OpenAI. First make your own copy of the settings file — pick your system:

cp .env.example .env
copy .env.example .env

Then open the new .env file and paste your key after OPENAI_API_KEY=:

OPENAI_API_KEY=sk-your-key-goes-here
📸 Placeholder — screenshot of the key pasted into the .env file.
🔒
Keep this key private. Never post it publicly or share it online — treat it like a password.
04

Run the bot

Install the pieces it needs, then start it:

npm install
npm run dev

Open http://localhost:3000 in your browser and say hi to Hermes.

🎉That's a real AI bot running on your machine. Now let's make it yours.
05

Install OpenChamber

OpenChamber is the AI coding assistant we'll use to build new features. Download it at openchamber.dev/download.

Pick Apple Silicon (M1–M4 chips) or Intel (older Macs). Open the file and drag OpenChamber into Applications.

Download the x64 build and run the installer.

OpenChamber runs on a tool called OpenCode. Install it once — this line works on every system:

npm install -g opencode-ai

Open OpenChamber and paste the same OpenAI key when it asks for a provider key.

Troubleshooting

Stuck? Start here.

'node' / 'npm' is not recognized+
Close your terminal, reopen it, and try again. Still stuck? Reinstall Node.js from nodejs.org and restart your computer.
command not found: git+
Install Git from git-scm.com, then close and reopen your terminal.
Bot says “No OPENAI_API_KEY found”+
Your .env file is missing or the key isn't pasted in. Redo Step 3. Make sure the file is named exactly .env — not .env.txt.
The chat says “Sorry, I hit an error”+
Your key may be wrong or out of credit. Re-copy it carefully into .env and restart the bot.
port 3000 already in use+
Something else is using that port. On Mac run PORT=3001 npm run dev; on Windows run set PORT=3001 && npm run dev, then open http://localhost:3001.
Mac won't open OpenChamber (“unidentified developer”)+
Right-click the app icon → Open → Open. You only need to do this once.
Windows SmartScreen warning+
Click More info → Run anyway.
